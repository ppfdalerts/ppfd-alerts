How do the colors work?
  1. Subscribe to each work-code calendar you want.
  2. Choose each calendar’s color inside Apple Calendar, Google Calendar, or Outlook.
  3. Keep those subscriptions. Their links stay the same as the roster updates.

The website’s colors are suggestions; your calendar app controls the actual colors. If a new work code appears later, add its calendar too. The one-calendar option includes new codes automatically.

Using Google Calendar or Outlook?

Choose Copy calendar link for one calendar, or Copy link beside each work code. In your calendar app, choose to add a calendar from a URL or subscribe from the web, then paste the link. Subscribe rather than importing a one-time file.
